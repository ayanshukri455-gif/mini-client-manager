# Mini Client Manager

Лек и адаптивен уебсайт за управление на клиенти, изграден с HTML, CSS и чист JavaScript. Проектът не изисква сървър, база данни или допълнителни библиотеки.

## Функционалности

- Табло със статистика за клиентите.
- Таблица с 5 примерни клиента (всички данни са измислени).
- Добавяне на клиент чрез форма с име, фирма и имейл.
- Изтриване на клиент с потвърждение.
- Търсене по име, фирма или имейл.
- Локално запазване чрез `localStorage` — данните остават в същия браузър.
- Адаптивен дизайн за компютър и мобилни устройства.

## Стартиране

1. Изтегли или клонирай repository-то.
2. Отвори папката `mini-client-manager` във Visual Studio Code.
3. Отвори `index.html` в браузър. По желание използвай разширението **Live Server** във VS Code.

Няма нужда от `npm install` или друга инсталация.

## Структура

```text
mini-client-manager/
├── index.html   # Структура и съдържание на страницата
├── style.css    # Визия, цветове и адаптивен дизайн
├── script.js    # Данни, добавяне, търсене и изтриване
└── README.md    # Описание и инструкции
```

## Как работи

- `index.html` съдържа менюто, статистиката, таблицата и формата.
- `style.css` оформя интерфейса и адаптира изгледа за по-малки екрани.
- `script.js` зарежда примерните клиенти, визуализира таблицата и обработва действията. `localStorage` пази промените локално в браузъра.

## Ограничения

Това е демонстрационен проект без сървър и потребителски акаунти. Данните са локални за конкретния браузър и устройство; не се синхронизират между различни потребители.
